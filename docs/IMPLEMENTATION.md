# Implementation and verification

The 9 October 2026 build request authorizes implementation, superseding the original documentation-only status. PRD.md governs intended behavior. The user requested local verification before configuring deployment.

## Implemented

- Shared, validated millimetre document model; bounded geometry, units, wall openings and door sectors.
- React/Vite planner: rectangle/L rooms, 30 first-party furniture pieces, custom shapes, precise numeric edits, grid/wall snapping, ruler, fit warnings and undo/redo.
- Independent alternatives, owned/to-buy budgets, per-item colours/materials and per-wall colours shared by the 2D and lazy-loaded 3D renderers.
- Detailed procedural furniture: upholstered seats, backs, cushions, bed linen, table legs/pedestals, chair backs, shelving, drawers and lamps; shared grain/weave textures, windows, doors and wall cutaways.
- IndexedDB device saves, isolated guest/account partitions, recovered copies on competing-tab writes, Trash and import with fresh identifiers.
- Vector PDF with embedded licensed font, 2D and camera-view PNG, CSV and validated restorable plan files.
- Workers/D1 owner-scoped API, official Better Auth OTP/session schema, conditional revision updates and mutation retries; persistent sync queue, offline handling, conflict recovery and explicit guest-copy consent.
- Cloudflare Email Sending binding and optional Resend adapter. Delivery remains disabled locally.

## Automated evidence

- Geometry, commands, models, 30 furniture bounds, colour propagation, exports, sync retries/in-flight generation acknowledgments, conflict recovery during concurrent edits and failed refresh retries, deleted originals, account-separated guest uploads, queued Trash transitions and competing-tab saves: **30 unit tests passed**.
- Actual Workers/D1 runtime: **3 integration tests passed**. Scenarios include hashed OTPs, concurrent consumption, replay/expiry/attempt limits, sessions, owner isolation, simultaneous conditional saves, mutation reuse, Trash/restore and request-origin checks.
- Chromium at 1440×900 and a 360×800 touch viewport: **8 end-to-end checks passed** for numeric placement/editing, independent alternatives, persisted colours, reload, all exports, fresh-ID import, Trash restore and WebGL fallback.
- Automated axe checks reported no violations for selected WCAG A/AA rules on landing, editor, export dialog, project list and sign-in at both viewports. Furnished-room checks verified table/chair colours and 20 repeated 2D/3D switches per viewport. This is a renderer smoke test, not a measured memory benchmark.
- Formatting, ESLint, strict TypeScript, production Vite build and local Worker dry-run bundling passed. Reapplying local D1 migrations reported no pending migrations. The initial editor dependency graph is approximately 276 KB gzip; 3D (~250 KB gzip) and PDF/fontkit (~507 KB gzip) load only on demand.

Screenshots and retained failure traces are generated by repository tests. Mobile emulation proves responsive behavior; it does not prove physical-device frame rate or memory targets.
